# Freelance Lead Hunter AI

Phase 1 is a standalone Angular frontend for a freelance lead discovery workspace. It uses PrimeNG with the Aura preset, PrimeIcons, SCSS, Angular signals, and local TypeScript mock data.

## Run locally

```bash
npm install
npm start
```

Open the local URL printed by Angular CLI. Create a production build with:

```bash
npm run build
```

## Demo scope

- Dashboard and Business Discovery are available; other navigation items are roadmap placeholders.
- Search, table filters, sorting, pagination, and CSV export use only the 13 supplied salon names for Bhavnagar, Gujarat.
- Ratings, review counts, and website URLs were not provided, so they remain unknown. Website status is `Unverified` for every record.
- Google Maps and OpenStreetMap options are labeled future integrations and do not call external services.
- Light and dark mode preference is stored locally in the browser.

No backend, database, or external business data integration is included.
